# Gökyüzü Aidat Hesaplayıcı

## Resmi Duyuru

Bu yazılım, vatandaşların gökyüzünü izinsiz kullanmasının önüne geçmek amacıyla geliştirilmiş **ulusal öneme sahip** bir kamu maliyesi aracıdır.

Gökyüzü boş değildir. Gökyüzü bir ortak alandır. Ortak alan aidatsız olmaz. Bu kadar.

## Kurulum

```bash
python3 aidat.py
```

Başka bir şey gerekmez. Gerekseydi bildirirdik.

## Yöntem

1. Program çalışır.
2. Sizin yerinize gökyüzüne bakar.
3. Tarifeyi uygular.
4. Makbuz basar.
5. Siz ödemezsiniz. Sistem bunu bekler.
